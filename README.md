# Schnittstellen

Ein Visual-Studio-Projekt zur Einführung in die Definition und Verwendung von Schnittstellen (Interfaces) in der objektorientierten Programmierung.

## Beschreibung

Das Projekt **Schnittstellen** beschäftigt sich mit den Grundlagen der Verwendung von Interfaces in C#. Schnittstellen ermöglichen es, gemeinsame Verträge für Klassen zu definieren und eine einheitliche Struktur für unterschiedliche Implementierungen festzulegen.

Im Mittelpunkt stehen die Definition und Implementierung von Schnittstellen sowie die flexible und erweiterbare Gestaltung von Anwendungen.

## Funktionen

- Definition und Verwendung von Interfaces
- Implementierung von Schnittstellen in Klassen
- Festlegung gemeinsamer Methoden und Eigenschaften
- Verwendung unterschiedlicher Implementierungen
- Grundlagen der Polymorphie
- Einführung in die lose Kopplung von Softwarekomponenten

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Objektorientierte Programmierung (OOP)
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/Schnittstellen.git
   ```

2. Die Datei `Schnittstellen.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
